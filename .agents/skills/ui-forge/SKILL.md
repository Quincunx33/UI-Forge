# UI-Forge Skill Entry Point

The canonical, full UI-Forge skill is maintained at `skills/ui-forge/SKILL.md`.

Before handling a UI/frontend task, read that file and follow its mode selection. UI-Forge creates polished frontends as well as reviewing, detecting, repairing, and verifying existing interfaces.

Load the focused workflow that matches the request:
- `skills/ui-create/SKILL.md` for new frontend design/builds and explicitly requested substantial redesigns.
- `skills/ui-design-review/SKILL.md` for read-only visual critique.
- `skills/ui-detect/SKILL.md` for read-only bug detection.
- `skills/ui-repair/SKILL.md` for narrow, explicitly authorized defect fixes.

Do not route every request to repair. Preserve the distinction between creating a new design, reviewing an existing one, detecting defects, and narrowly repairing code. Adapt tool usage to the host environment and report unavailable checks as untested.
