# Repository instructions

For UI/frontend tasks, read `.agents/AGENTS.md` and `.agents/skills/ui-forge/SKILL.md` before acting. Load the focused skill from `skills/ui-detect/SKILL.md`, `skills/ui-design-review/SKILL.md`, or `skills/ui-repair/SKILL.md` when relevant.

Default to evidence-first inspection. Detection and design review must not edit source files. Repair requires a clear user request, minimal scoped changes, and regression verification. Preserve the project's existing stack and design system. Never claim browser checks, tests, or visual observations that were not actually performed.
