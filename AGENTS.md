# Repository instructions

For UI/frontend tasks, read `.agents/AGENTS.md` and `.agents/skills/ui-forge/SKILL.md` before acting.

Choose the focused workflow:
- `skills/ui-create/SKILL.md`: build a new frontend or implement an explicitly requested substantial redesign.
- `skills/ui-design-review/SKILL.md`: critique an existing design without editing.
- `skills/ui-detect/SKILL.md`: inspect and report defects without editing.
- `skills/ui-repair/SKILL.md`: narrowly fix confirmed defects while preserving current design and behavior.

UI-Forge creates polished frontend experiences; it is not limited to existing-code repair. Preserve the existing stack and product behavior, use actual visual evidence when available, and never claim browser checks, tests, or visual observations that were not performed.
